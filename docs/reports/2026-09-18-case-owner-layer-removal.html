How Case Ownership Works Now

September 2026 Update

Date: September 18, 2026 (Updated September 19)

Status: ✓ Completed and Live in Production

What's This About?

We simplified how the CRM handles case ownership. Previously, there were multiple complicated ways a person could "own" or be responsible for a case. Now it's simpler: the person or team who manages the customer account is automatically responsible for all their cases.

The Simple Change

Instead of manually assigning case owners (which was complicated and often inconsistent), the system now automatically uses the account manager(s) as the case owner(s). This means:

  • Faster: No need to manually add or remove case owners
  • Accurate: Changes to account managers are instantly reflected on all their cases
  • Simpler: One rule instead of multiple overlapping ones

What Changed in the System

Area How It Used To Work How It Works Now
Who Can See a Case Person manually assigned as owner could see it Account manager automatically sees all their account's cases
Adding a Manager Had to manually update each open case's ownership Automatic — new manager sees all cases immediately
Closed Cases Ownership was frozen when case closed Ownership updates live, even on closed cases
Case Without a Manager Only the person who created it could see it Only the creator can see it (until a manager is assigned)
Manually Adding Owners Could add someone who wasn't a manager as owner Not possible anymore — only managers own cases
Case Page Display Showed "Owners" with a manage button Shows "Handlers" as read-only list
"My Cases" Dashboard Showed cases you were assigned to Shows accounts you manage and their cases
Behind the Scenes Two separate systems tracked ownership One unified system for all ownership

Who Loses Access to What?

These changes mean two groups will lose access to certain cases:

1. People Who Created Cases on Unmanaged Accounts

If you created a case for an account that didn't have a manager yet, and then a manager was assigned to that account, you'll no longer see that case (unless you're also the ticket holder). Before the change, you would keep seeing it.

2. People Who Were Manually Added as Owners

If someone manually added you as an owner of a case (without making you a manager), you'll no longer have access to that case after this change. There's no way to do this anymore — only managers can own cases now.

Something to Know About Sales Reports

Won case credit will update retroactively: When a case is marked as won, credit goes to the current manager of that account. If you later change who manages an account, past won cases will now show credit for the new manager instead. This is automatic.
